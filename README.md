## 🚀 Highlighted Engineering Projects / Dự Án Tiêu Biểu

### 1. [Indoor Fall Detection via 24GHz FMCW mmWave Radar & FSM](https://github.com/Hoangduyy-1812/DO_AN_2_table)
- **Tech Stack:** `ESP32`, `FreeRTOS`, `HLK-LD2450 mmWave Radar`, `TCP/IP Bridge`, `Python`, `Web Dashboard 60FPS`
- **EN:** Developed an edge-assisted fall detection system. Implemented bit-level binary parsing for the LD2450 sensor (UART 256k bps) and a robust 4-state Finite State Machine (FSM) to distinguish actual falls from daily activities. Achieved **100% file-level classification** on independent test sets (24/24 files) and **0 false alarms** on normal activities. Integrated an asynchronous TCP receiver and real-time dark-tech web telemetry interface.
- **VI:** Xây dựng hệ thống phát hiện té ngã trong nhà. Tự phát triển module giải mã bit-level giao thức radar mmWave 24GHz và thuật toán FSM 4 trạng thái nhận diện động học rơi tự do (đạt độ chính xác 100% trên tập test 24 file độc lập, 0 báo động giả khi sinh hoạt bình thường). Tích hợp cầu truyền dữ liệu TCP FreeRTOS và giao diện Web Dashboard giám sát thời gian thực 60 FPS.

### 2. Multi-Channel High-Precision DAQ System
- **Tech Stack:** `STM32 (ARM Cortex-M)`, `Embedded C`, `24-bit AD7124 ADC`, `SPI`, `Altium Designer`
- **EN:** Designed firmware and analog front-end interface for high-precision sensor telemetry. Optimized SPI communication timing and register configurations for noise suppression and stable multi-channel sampling.
- **VI:** Thiết kế firmware và phần cứng thu thập dữ liệu (DAQ) độ phân giải cao sử dụng STM32 và ADC 24-bit AD7124 qua giao tiếp SPI, tối ưu hóa thanh ghi và lọc nhiễu tín hiệu.

### 3. Industrial Concrete Curing SCADA & Control Cabinet
- **Tech Stack:** `Python`, `RS485 Modbus RTU`, `Industrial Automation`, `GUI`
- **EN:** Developed a PC-based SCADA interface communicating via RS485 Modbus RTU to monitor and automate multi-zone temperature/humidity curing cycles in industrial environments.
- **VI:** Xây dựng phần mềm SCADA trên PC kết nối mạng công nghiệp RS485 Modbus RTU để điều khiển tự động và giám sát nhiệt độ - độ ẩm cho tủ dưỡng hộ bê tông.

### 4. Wireless Sensor Network (WSN) Evaluation
- **Tech Stack:** `Contiki OS`, `Cooja Simulator`, `RPL Protocol`, `6LoWPAN`
- **EN:** Analyzed power consumption and network duty cycles under multiple RPL objective functions for resource-constrained IoT nodes.
- **VI:** Mô phỏng, đo kiểm chu kỳ hoạt động (duty cycle) và tối ưu hóa năng lượng cho mạng cảm biến không dây (WSN) sử dụng hệ điều hành nhúng Contiki OS và bộ mô phỏng Cooja.
